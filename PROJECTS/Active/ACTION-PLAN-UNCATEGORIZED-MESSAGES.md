## Problem Statement

Messages in Smartlead Master Inbox have **category tags** (e.g., "Rachel - Global Brands 6") but are **missing reply-status tags** (Interested, Follow-up, Not Interested, etc.) that the automation requires to sync to Pipedrive.

**Impact:** These leads sit in Smartlead but don't automatically sync to Pipedrive, breaking the lead-management workflow.

---

## Solution

Apply the correct **reply-status tags** to each uncategorized message based on the message content.

---

## Step-by-Step Process

### Step 1: Access Smartlead Master Inbox
1. Open Smartlead (app.smartlead.ai)
2. Click "Master Inbox" in left sidebar
3. Review messages without reply-status tags

### Step 2: Categorize Each Message
For each uncategorized message, read the content and apply ONE of these tags:

| Tag | When to Use | Example |
|-----|------------|---------|
| **Interested** | Explicit interest / Call request | "Yes, let's set up a call" |
| **Follow-up** | Asking for info/pricing | "Can you send pricing details?" |
| **Not Interested** | Explicit rejection | "This doesn't fit our needs" |
| **Do Not Contact** | Unsubscribe request | "Remove me from list" |
| **Unsure** | Unclear meaning | Ambiguous message |

### Step 3: Block Domain (For Interested/Follow-up)
1. After tagging as "Interested" or "Follow-up"
2. Click **"Block"** → **"Block entire domain"**
3. Confirm

### Step 4: Verify Sync
After tagging 2-3 messages, check Pipedrive:
1. Open Pipedrive
2. Look for new Persons with tagged messages
3. Confirm Activities are created with "Interested"/"Follow-up" label

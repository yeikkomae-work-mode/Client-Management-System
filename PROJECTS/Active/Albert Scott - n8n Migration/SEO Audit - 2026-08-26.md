## The one fix that clears the biggest error (113 objects)

**`ogp-missing` — 113/113 objects flagged.** Every single page, post, and project on the site is missing Open Graph tags. Root cause confirmed in AIOSEO's Social settings: there is no default share image configured anywhere (`facebook.general.defaultImagePosts` is empty, homepage OG image/title/description are all blank, no fallback set). Every link shared to Facebook/LinkedIn/Slack/iMessage currently renders with no preview image or custom title.

**Fix:** set a default Facebook/OG share image (and ideally per-page images on top content) in AIOSEO → Social Networks → Facebook. This single setting resolves the largest error bucket site-wide in one change.

## Site-wide technical checks

- **Sitemaps**: present and current (`sitemap.xml` index → post/page/project/category/tag sitemaps), all generated by AIOSEO, last updated within days.
- **robots.txt**: clean — only disallows `/wp-admin/` (with the ajax exception) and `/cdn-cgi/`. No accidental blocking of content.
- **Schema markup**: 113/113 passing (`schema-ok`) — structured data is in good shape.
- **Canonical URLs**: 105/113 passing, 8 missing.
- **Search Console / Search Statistics**: **not connected** (`"Not connected to the Search Statistics service"`). This means no rank tracking, no indexing-status visibility, and no click/impression data flowing into AIOSEO at all right now — worth connecting Google Search Console via AIOSEO's Search Statistics module.
- **Webmaster verification tags**: Google, Bing, Yandex, Baidu, Pinterest, Norton — all empty. No verification meta tags are set for any search engine, consistent with Search Console not being connected.
- **Social profile URLs**: none set (Facebook, Twitter/X, Instagram, LinkedIn, YouTube, etc. all blank) — this also means the Organization schema's `sameAs` field is empty, a missed authority signal for Google's Knowledge Graph.
- **Site Kit by Google**: plugin is installed and active, but not confirmed connected/authorized (would need a browser-based OAuth check to verify — REST API alone doesn't expose connection status cleanly without further calls).

## Recommended priority order

1. **Set a default OG/social share image** (AIOSEO → Social Networks → Facebook) — fixes 113 errors in one change.
2. **Review and deindex/remove the test pages** (`test page`, `test-modules`, `form-ads-test`) and fix the `Clients` page's broken permalink.
3. **Connect Google Search Console** via AIOSEO Search Statistics — currently flying blind on rankings/indexing.
4. **Batch-fix missing meta descriptions** (31 pages with none) and **missing image alt text** (86 images) — both are mechanical, high-volume fixes.
5. **Add focus keywords** to the 93 objects missing one, starting with the highest-traffic pages, to actually use AIOSEO's on-page optimization scoring.
6. **Set social profile URLs** in AIOSEO for schema `sameAs` and to fully enable Twitter/Facebook card previews.
7. Manually review the 11 `noindex`'d objects to confirm none of them are pages that should actually be indexed.

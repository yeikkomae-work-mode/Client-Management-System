TROUBLESHOOTING:
  Problem: "npm install" fails
  Solution: Check Node.js version (need >=18): node --version

  Problem: Port 3001 already in use
  Solution: Change PORT in backend/.env or kill process using port

  Problem: Backend not responding
  Solution: Verify it's running: curl http://localhost:3001/health

  Problem: Files not being detected
  Solution: Verify file is .md and in /PROJECTS/Active/ or /OUTPUT/End-of-Day Reports/

  For more help: See PHASE-2.5-README.md section on troubleshooting

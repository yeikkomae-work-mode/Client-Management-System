# How to Use — Plugin Templates

**Plugin = Reusable templates you can apply to any client (current or future).**

---

## WHAT'S IN THE PLUGIN

```

├── 02 Plugin Client Templates.md            (Original spec)
├── How to Use - Plugin Templates.md         (This file)
├── Template - Client Onboarding.md
├── Template - Daily Task Checklist.md
├── Template - Campaign Metrics.md

└── Template - Meeting Summary.md
```

**5 templates you can copy, customize, and reuse:**

1. **Client Onboarding** — Set up a new client or revisit existing client info
2. **Daily Task Checklist** — Create repeatable daily workflow
3. **Campaign Metrics** — Track any campaign's performance
4. **Message Check** — Audit messages from a client
5. **Meeting Summary** — Process meeting transcripts

---

## WORKFLOW

### FOR NEW CLIENTS

**Step 1:** Fill in Client Onboarding template
- Basic info, contact, tools, tasks
- Save to `Important info.md`

**Step 2:** Create Daily Task Checklist
- Copy template, customize for their workflow
- Save as `/Build-out/02 Plugin Client Templates/Checklists/[Client Name].md`

**Step 3:** Set up Campaign Metrics (if applicable)
- If they have campaigns, create template
- Reference in daily checklist

**Step 4:** Add to automation
- Include in daily "good morning" workflow
- Add to work logger for tracking

---

### FOR EXISTING CLIENTS

**Review & refresh:**
1. Check Client Onboarding — anything changed?
2. Review Daily Task Checklist — still accurate?
3. Update if workflows shifted

**Use templates as-needed:**
- Campaign Metrics when launching new campaigns
- Message Check during daily routine
- Meeting Summary for any meetings

## DETAILED GUIDE

### TEMPLATE 1: Client Onboarding

**When to use:**
- Adding a new client
- Quarterly review of existing client
- Contract change or role shift

**What to fill in:**
- Contact info (email, WhatsApp, timezone)
- Your role & engagement type
- Tools you'll use
- Daily/recurring tasks
- Communication style
- Payment info (if relevant)
- Projects assigned
- Key workflows
- Important notes

**Where it goes:**
- Save summary to `Important info.md`
- Keep detailed version in project folder

**Result:**
- You have complete client profile
- New teammate could jump in with context
- Easy to onboard or check status anytime

---

### TEMPLATE 2: Daily Task Checklist

**When to use:**
- Creating workflow for a new client
- Standardizing a messy workflow
- Quarterly review of tasks (are they still needed?)

**What to fill in:**
- Morning check (emails, messages, etc.)
- Core work (tool-specific tasks)
- Data logging
- End of day (review & log)
- Time estimates
- Notes on blockers

**Customize:**
- Add/remove tasks based on client's actual needs
- Adjust time estimates
- Create "light day" and "heavy day" variations

**Where it goes:**
- Save as `/Build-out/02 Plugin Client Templates/Checklists/[Client Name] - Daily Checklist.md`
- Reference in your "good morning" recap
- Update quarterly

**Result:**
- Clear daily workflow
- Consistent execution across days
- Easy to estimate time needed

---

### TEMPLATE 3: Campaign Metrics

**When to use:**
- Starting a new campaign
- Tracking existing campaign progress
- Weekly/daily metric reviews
- Communicating progress to client

**What to fill in:**
- Campaign name, tool, target
- Current metrics (sent, open %, reply %, bounces, conversions)
- Trend data (if tracking over days/weeks)
- Performance analysis (what's working, what's not)
- Next steps

**Variations:**
- **Minimal:** Just key metrics
- **Detailed:** Full tracking
- **Trending:** Multi-week view

**Where it goes:**
- In `End-of-Day Reports/[Client Name] - End of Day Log.md` under daily entry
- Or as separate file: `End-of-Day Reports/[Client Name] - [Campaign] - Metrics.md`

**Result:**
- Clear visibility into campaign health
- Easy to spot trends
- Data-driven decisions on what to adjust

---

### TEMPLATE 4: Message Check

**When to use:**
- Daily morning routine (check all messages)
- End of day audit (catch anything missed)
- Periodic catch-up (between work sessions)

**What to fill in:**
- Email: count, urgent messages, key updates
- WhatsApp: count, urgent messages, key updates
- Slack/Teams (if applicable): same
- Summary: blockers, action needed, follow-up

**Variations:**
- **Quick check:** 2 minutes, just counts and urgent flag
- **Detailed check:** 10 minutes, full review per channel

**Where it goes:**
- Log in daily routine or end-of-day recap
- Reference in work logger if message reply is task

**Result:**
- Nothing slips through
- Clear visibility of urgent vs. non-urgent
- Quick summary for client communication

---

### TEMPLATE 5: Meeting Summary

**When to use:**
- After any meeting with a client
- Processing call/meeting transcripts
- Capturing decisions & action items

**What to fill in:**
- Meeting info (date, attendees, platform)
- Summary (2-3 sentences)
- Action items (what, who, when)
- Key decisions
- Q&A (if relevant)
- Blockers identified
- Next meeting (if scheduled)

**How to use:**
1. You have meeting (Teams, Zoom, phone, in-person)
2. Export/record transcript
3. Paste transcript in chat: "Transcript for [Client] — [Date]"
4. I'll process it or you can fill template manually
5. Store summary

**Where it goes:**
- `End-of-Day Reports/[Client Name] - End of Day Log.md` under date section
- Or: `Build-out/02 Plugin Client Templates/Meetings/[Client] - [Date] - Summary.md`

**Result:**
- Clear record of what was discussed
- Action items tracked
- No miscommunication on next steps
- Historical reference for future meetings

## WHEN TO REFRESH TEMPLATES

**Quarterly:** Review each template for accuracy
- Are tasks still the same?
- Do time estimates still hold?
- Any new tools added?
- Communication style changed?

**After big changes:**
- New project from client
- Client adds/drops tools
- Role or focus shifts
- Client scaling up/down

**Annually:**
- Full audit of all templates
- Archive old versions
- Refactor if workflows evolved

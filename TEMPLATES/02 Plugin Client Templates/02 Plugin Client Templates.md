# 02 Plugin Client Templates — Spec

**Purpose:** Reusable templates Eikko can apply to current and future clients. These templates speed up onboarding new clients and keep workflows consistent.

**Components:**
1. Client Onboarding Template
2. Daily Task Checklist Template (generic)
3. Campaign Metrics Template
4. Email/Message Check Template
5. Meeting-to-Summary Workflow

---

## 1. Client Onboarding Template

**Use this when adding a new client.**

```
CLIENT ONBOARDING — [Client Name]

CONTACT INFO
- Full name: 
- Email: 
- WhatsApp: 
- Slack: 
- Other channels: 
- Timezone: 
- Preferred contact method: 

ROLE & ENGAGEMENT
- My role: 
- Type: (Full-time / Part-time)
- Hours per week: 
- Start date: 
- Rate/contract type: 
- Company name (if applicable): 

TOOLS I'LL USE
- [Tool 1] — for [task]
- [Tool 2] — for [task]
- [Tool 3] — for [task]
- API access needed? (Yes/No) — which APIs?

DAILY/RECURRING TASKS
1. [Task 1] — frequency: 
2. [Task 2] — frequency: 
3. [Task 3] — frequency: 

COMMUNICATION STYLE
- How often should I check in? 
- Preferred update frequency: 
- Meeting schedule: 
- Emergency protocol: 

KEY NOTES
- [Anything special about this client]
- [Workflow details]
- [Blockers or dependencies]

PROJECTS ASSIGNED
- Project 1: [name]
- Project 2: [name]
```

## 2. Daily Task Checklist Template (Generic)

**Use this for any new client's daily routine.**

```
DAILY CHECKLIST — [Client Name] — [Date]

MORNING CHECK (5-10 min)
☐ Check emails for updates/requests
☐ Check WhatsApp for messages
☐ Check [other tool: Slack/chat/etc] if applicable
☐ Note any urgent items
☐ Review task carry-over from yesterday

CORE WORK (time varies)
☐ [Tool 1: specific task] — e.g., "Check Apollo for new replies"
☐ [Tool 2: specific task] — e.g., "Monitor campaign in Hubspot"
☐ [Tool 3: specific task] — e.g., "Update CRM with new data"
☐ [Tool 4: specific task]

DATA LOGGING
☐ Log campaign metrics
☐ Update task completion status
☐ Note blockers or next steps

END OF DAY
☐ Create work log entry (goal → accomplishment)
☐ Note what carries to tomorrow
☐ Flag any urgent items for client

Time estimate: [X minutes]
```

## 3. Campaign Metrics Template

**Use this to track campaign performance per client/tool.**

```
CAMPAIGN METRICS — [Client] — [Campaign Name] — [Date]

OVERVIEW
- Campaign name: 
- Tool: (Hubspot/Lemlist/PlusVibe/Smartlead/Pipedrive/etc)
- Date started: 
- Target: [# contacts or goal]

KEY METRICS
- Emails/leads sent: [#]
- Open rate: [%]
- Click rate: [%]
- Reply rate: [%]
- Bounces: [#]
- Unsubscribes: [#]
- Conversions/deals: [#]

STATUS
- Current phase: (Drafting / Sending / In-progress / Completed)
- Performance vs. target: (On track / Lagging / Exceeding)
- Issues or notes: 

NEXT STEPS
- [Action 1]
- [Action 2]

TREND (if tracking over time)
- Week 1: [Metric]
- Week 2: [Metric]
- Week 3: [Metric]
```

## 4. Email/Message Check Template

**Use this for any client with regular message checking.**

```
MESSAGE CHECK — [Client] — [Date]

EMAIL
- Unread count: [#]
- Urgent emails: [List]
- Key updates: [Summary]
- Action required: [Yes/No] — [Details]

WHATSAPP
- New messages: [#]
- Urgent messages: [List]
- Key updates: [Summary]
- Action required: [Yes/No] — [Details]

SLACK (if applicable)
- New messages: [#]
- Urgent messages: [List]
- Key updates: [Summary]
- Action required: [Yes/No] — [Details]

SUMMARY
- Any blockers? 
- Any requests from client? 
- Follow-up needed? 

Time to check: [# minutes]
```

## 5. Meeting-to-Summary Workflow

**Use this for any client meeting.**

```
MEETING SUMMARY — [Client] — [Date]

MEETING INFO
- Attendees: 
- Duration: 
- Platform: (Zoom/Google Meet/Phone/In-person/etc)
- Transcript: [Attached/Available: Yes/No]

WHAT WAS DISCUSSED
[2-3 sentences summarizing main topics]

ACTION ITEMS
- [ ] [Action] — Owner: [Who] — Due date: [Date]
- [ ] [Action] — Owner: [Who] — Due date: [Date]
- [ ] [Action] — Owner: [Who] — Due date: [Date]

KEY DECISIONS
- [Decision 1]
- [Decision 2]

QUESTIONS ANSWERED
- Q: [Question] → A: [Answer]

BLOCKERS IDENTIFIED
- [Blocker 1]
- [Blocker 2]

NEXT STEPS
- Next meeting: [Date & time, if scheduled]
- Prep needed: [If any]

NOTES
[Any other important details from meeting]
```

# Work Logger Prompt — Log Your Tasks

**Use this:** Whenever you start a task or finish a task during your work day.

---

## START A TASK

**Use this format when you begin work:**

```
STARTING WORK

Client: [Chris Caffera / Chris Drew / Yoni / Krishna / Chris Soriano]
Task: [What am I doing? e.g., "Check Apollo for new replies"]
Goal: [What I want to accomplish, e.g., "Review 50 new replies and tag quality ones"]
Start time: [Auto: current time]
```

**What I do:**
- I note the task, goal, and time
- You work on it
- When done, you log completion

---

## FINISH A TASK

**Use this format when you complete work:**

```
COMPLETED WORK

Client: [Client name]
Task: [What you worked on]
Goal: [What you aimed to accomplish]
Accomplished: [What you actually got done — be specific]
Time spent: [e.g., 45 minutes]
Blockers: [Any issues? Or "None"]
Notes: [Optional next steps or follow-up]
```

**Example:**

```
COMPLETED WORK

Client: Yoni
Task: Tag prospects in Smartlead and move to Pipedrive
Goal: Process 30 new replies, tag as interested/not interested, move interested ones
Accomplished: 
  - Tagged 28 replies (20 interested, 8 not interested)
  - Moved 20 interested prospects to Pipedrive
  - Added 8 uninterested emails to blocklist
Time spent: 1 hour 15 minutes
Blockers: None
Notes: 3 prospects still pending replies, will check again tomorrow
```

---

## THROUGHOUT YOUR DAY

- **After each task/session:** Paste a "COMPLETED WORK" entry
- **At end of day:** I'll compile all your entries for tomorrow's recap
- **No need to track time manually** — just estimate if you don't have exact minutes

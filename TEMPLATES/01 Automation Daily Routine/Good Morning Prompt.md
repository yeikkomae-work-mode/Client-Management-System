# Good Morning Prompt — Daily Automation

---

## GENERATE

Based on the above, I will:

1. ✓ **Pull API data** from Smartlead, Pipedrive (and any newly connected tools)
2. ✓ **Combine with your manual metrics** (Hubspot, Lemlist, LinkedIn, etc.)
3. ✓ **Generate YESTERDAY'S RECAP** (organized by client)
4. ✓ **Show TODAY'S CHECKLIST** (what to focus on per client)
5. ✓ **Process any meeting transcripts** (if provided)
6. ✓ **Ready the work logger** (for today's tasks)

## HOW TO USE

1. **At end of your work day** when you say "done for today":
   - I'll ask you for metrics (Hubspot, Lemlist, LinkedIn, etc.)
   - You provide them
   - I store them for tomorrow

2. **Whenever you're ready** when you say "good morning":
   - I pull API data (Smartlead, Pipedrive, TimeDoctors)
   - I use yesterday's manual metrics
   - I generate your recap + today's checklist
   - Ready to work

3. **If you have a meeting transcript:**
   - Anytime: "Transcript for [Client]" → paste transcript
   - I'll process it and include in next recap

---

**Just say "good morning" when you're ready to start your day.**
